# Yapnest 1.0 (9)

## Fixed

- A chat you read on one device no longer stays unread on another that
  was in the background meanwhile. Reading several chats then used to
  reach it only for the last one, until Yapnest was restarted. The same
  went for groups joined, left or renamed, and settings changed, on
  another device. On the Mac, all of these now arrive straight away even
  while Yapnest's window is hidden or minimized.
- A message that couldn't be delivered now gives the server's reason in
  its details.
- Joining a group from an invitation while the server is slow no longer
  says the group doesn't exist, and creating a group while the server is
  slow says so, instead of saying the server doesn't host groups.
- An edit, a deletion or a reaction the other side never got now says
  so, with a way to try again, instead of looking delivered. A message
  to someone who is briefly unreachable is sent again a few times
  rather than failing at once.
- The exported logs no longer keep exact times, file sizes or the
  server's port, so they can't be matched to a message you sent or
  received. The system log no longer shows the server's own messages
  about a failure, or your encryption device ids.
- When something you asked the server for fails, the message now gives
  the server's reason in plain words, with a Retry button where trying
  again could help.
- What goes wrong in the background, like messages that couldn't all be
  fetched, notifications that couldn't be turned on, or a setting the
  server wouldn't take, now shows above the chat list, with the reason
  and a Retry. Requests that fail for a moment, such as a timeout or a
  busy server, are tried again by themselves first, including uploads
  and fetching a contact's encryption keys.
- Accepting a contact request that the server refused no longer clears
  it. Blocking someone who asked to be a contact now declines their request
  before the block, which used to stop the decline from reaching them.
- A password change whose answer never came no longer leaves you signed
  out later: Yapnest says it may have worked, and signs in with the new
  password if the old one stops working.
- Groups:
  - Rejoining no longer brings back a group that was deleted while you
    were away.
  - A group that couldn't be set up is removed, instead of staying
    behind locked.
  - Leaving works on servers without the newer bookmark storage.
  - An invitation the group refuses now says so.
  - Encrypted messages in a group now say so when they may not reach
    every member.
- Hanging up or declining a call while the connection is down now
  reaches the other side once it's back, and a call still ringing ends if
  the connection doesn't come back.
- Yapnest no longer stays stuck syncing when the server doesn't answer
  its first question, and a request that times out now fails on time,
  instead of up to 30 seconds late.
- Yapnest no longer gets closed by the system a few seconds after you
  leave it. It now hears that it's going to the background in time to let
  go of its files.
- Running a command, changing your profile or managing a group right
  after coming back to Yapnest now waits a few seconds for the
  connection to come back, instead of saying you are offline.
- A video call whose camera offers no picture size Yapnest can use now
  sends a moving pattern instead of nothing, which left the other side
  with a black picture.
- The camera button in a chat now says when Yapnest isn't allowed to
  use the camera, and where to turn it on, instead of opening the camera.
