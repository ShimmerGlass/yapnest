# Yapnest 1.0 (9)

## Fixed

- A chat you read on one device no longer stays unread on another that
  was in the background meanwhile. Reading several chats then used to
  reach it only for the last one, until Yapnest was restarted. The same
  went for groups joined, left or renamed, and settings changed, on
  another device. On the Mac, all of these now arrive straight away even
  while Yapnest's window is hidden or minimized.
- A message that couldn't be delivered now gives the server's reason in
  its details.
- Joining a group from an invitation while the server is slow no longer
  says the group doesn't exist, and creating a group while the server is
  slow says so, instead of saying the server doesn't host groups.
