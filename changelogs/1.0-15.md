# Yapnest 1.0 (15)

## Changed

- An answered call is now two lines in the chat: "Outgoing call" or
  "Incoming call" when it began, and "Call ended" with its length when it
  ended, so what was said during the call sits between them. Calls you
  already have are split the same way.
- On iPhone, the call bar has a speaker button, in audio and video calls, and
  so does the video call screen, where Flip moved to the top corner to make
  room. It shows where the sound really is coming out.

## Fixed

- Mac: the call's Devices menu shows your microphones, speakers and cameras
  by name, instead of blank rows.
- When iOS starts Yapnest in the background, it no longer holds on to the
  connection, which could leave a new message without its notification.
  Quiet background pushes now fetch what's new and notify for it.
- Calls to a sleeping iPhone ring on an ejabberd server set to push only
  messages (`notify_on: messages`). Calls from other apps still don't ring
  there, as ejabberd doesn't push them.
- Fewer stray notifications on some servers, ejabberd in particular: the
  notification extension now picks up the app's connection where it left
  off, instead of opening its own and closing it, which could make the
  server send a run of extra notifications.
