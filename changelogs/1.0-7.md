# Yapnest 1.0 (7)

## Fixed

- A message with text pasted from a terminal (with control characters in
  it) is sent without them, instead of making the server drop the
  connection and holding up every message sent after it.
- A message the server drops the connection over each time it's sent is
  marked as failed after a few tries, so the messages after it go out. A
  reaction or edit it does that for is given up the same way.
- Editing a message into text too long to send says so, instead of
  showing the new text to you only.
