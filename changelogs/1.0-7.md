# Yapnest 1.0 (7)

## New

- On the Mac, clicking a picture opens it in Preview, and a file's menu
  has Save As… to save it wherever you choose.
- Where the chat list sits beside the open chat, its highlight slides to
  the chat you open.
- On the Mac, an opened chat's messages fade and rise into place.
- On the Mac, the Up arrow in an empty message field, or ⌘E, edits your
  last message.
- After you first sign in, a welcome screen asks what you want to share:
  encrypting new chats, read receipts, the typing indicator, last seen
  and GIF search. You can change each one later in Settings.
- Settings has Encrypt New Chats, to start new one-to-one chats without
  encryption. Chats you already have keep theirs.

## Changed

- Calls now write to the diagnostics log you can export from Settings:
  how long each step of setting one up took, the path the sound and
  picture take, and how steady they are, so a call that connects slowly
  or lags can be looked into. It holds no names or addresses.
- Opening Yapnest no longer says "Connecting…" while it connects, as that
  takes only a moment: it says so only once connecting takes more than a
  few seconds.

## Fixed

- On the Mac, a message you send slides into place smoothly instead of
  stuttering, and so does one that arrives while you're at the bottom.
- A chat with unread messages opens at them about twice as fast: the list
  no longer waits a fixed half second before showing.
- On the iPhone, a message arriving while you're scrolled up no longer
  moves the messages you're reading. New messages wait below, counted on
  the scroll to latest message button, until you scroll back down.
- A message with text pasted from a terminal (with control characters in
  it) is sent without them, instead of making the server drop the
  connection and holding up every message sent after it.
- A message the server drops the connection over each time it's sent is
  marked as failed after a few tries, so the messages after it go out. A
  reaction or edit it does that for is given up the same way.
- Editing a message into text too long to send says so, instead of
  showing the new text to you only.
- The scroll to latest message button lines up with the microphone button
  below it.
- On the Mac, the chat list leaves room between the search bar and a
  selected chat at the top.
