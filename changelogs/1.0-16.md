# Yapnest 1.0 (16)

## Fixed

- A call to an iPhone where Yapnest isn't open shows an "Incoming call"
  notification, and the person calling hears it ring instead of being told
  no device could take the call. Tapping it opens Yapnest, which rings the
  call if they are still waiting.
- After Yapnest was swiped away right after leaving it, calls, and group
  messages and contacts' status in rooms without a history archive, waited
  until Yapnest was opened again.
- On servers that push for everything (ejabberd set to `notify_on: all`),
  the iPhone no longer wakes every few seconds with nothing new, which cost
  battery: Yapnest waits for the answers it asked for before letting go.
- Each time a notification wakes the iPhone, Yapnest reads the history of
  only the groups that sent something, and all of them every 15 minutes,
  instead of every group each time, which was slow and cost battery when a
  busy group woke it every few seconds.
- When Yapnest can't fetch in time what a notification was for, it no
  longer shows a loud "New message" if the notification was only for a
  read marker, a reaction or a contact's status (on ejabberd with the
  push relay from 1.3.0).
